# 🎮 Zoro Game Store

**Zoro Game Store** is a full-featured web-based game store developed as a database-driven web application. The platform allows users to explore games, manage their shopping cart, place orders, and access game-related products, while administrators can manage the overall store through an admin panel.

The project was developed to demonstrate practical skills in **web development, database management, authentication, CRUD operations, and e-commerce system design**.

## ✨ Key Features

### 👤 User Features

* User registration and login
* Browse available games
* View game details
* Search and explore games
* Add games to cart
* Manage cart items
* Place orders
* View order information
* Access free monthly games
* Browse game merchandise

### 🛠️ Admin Features

* Secure admin panel
* Add, update, and delete games
* Manage users
* Manage orders
* Manage game merchandise
* Manage free monthly games
* Monitor store activities

### 🗄️ Database

* Relational database design using MySQL
* User and authentication data management
* Game and merchandise management
* Order and order-item relationships
* Payment-related data management

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/MRhimel01/Zoro-Game-store.git
```

### 2. Move the Project to XAMPP

Copy the project folder into:

```text
C:\xampp\htdocs\
```

The final path should be:

```text
C:\xampp\htdocs\Zoro-Game-store
```

### 3. Start XAMPP

Open XAMPP Control Panel and start:

```text
Apache
MySQL
```

### 4. Configure the Database

1. Open `phpMyAdmin`
2. Create a MySQL database
3. Import the project's SQL/database file
4. Configure the database connection file with your local MySQL credentials

### 5. Run the Application

Open your browser and visit:

```text
http://localhost/Zoro-Game-store/
```
